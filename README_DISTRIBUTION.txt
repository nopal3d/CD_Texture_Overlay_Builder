Distribution Notes for Nexus

For the public Nexus download, upload the complete ONEDIR portable folder as a ZIP.
Do not upload only CD_Texture_Overlay_Builder.exe.

Correct ZIP content:

CD_Texture_Overlay_Builder\
  CD_Texture_Overlay_Builder.exe
  _internal\
  SHA256SUMS.txt

Users should:

1. Extract the full ZIP.
2. Keep the EXE inside the extracted folder.
3. Run CD_Texture_Overlay_Builder.exe.

If a user receives a python DLL error, ask them to:

1. Re-extract the full ZIP.
2. Make sure antivirus did not quarantine _internal files.
3. Install Microsoft Visual C++ Redistributable x64.
4. Avoid moving the EXE out of its folder.
